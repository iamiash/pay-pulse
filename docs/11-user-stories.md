# 11. User Stories

### User Story 1: Encrypted Wallet Setup
* **As a** security-conscious user,
* **I want to** save my Bank Accounts, Cards, and Mobile Banking details with AES encryption,
* **So that** I can link them to subscriptions without exposing raw CVCs or full account numbers.

### User Story 2: Dynamic Subscription & Inline Payment Creation
* **As a** user adding a subscription,
* **I want** my contact info pre-filled and an inline option to add a missing payment method directly from the dropdown,
* **So that** I can complete the form without losing typed data or navigating away.

### User Story 3: 7-Day Renewal Notification
* **As a** busy subscriber,
* **I want to** receive notifications for subscriptions renewing within 7 days via an unread bell badge,
* **So that** I can cancel or adjust plans before auto-billing executes.

### User Story 4: Customizable PDF Exports
* **As a** user managing a budget,
* **I want to** export Full Summaries, Single Service Histories, Monthly Audits, and Advanced Date-Range Filtered PDFs,
* **So that** I have official records for expense accounting.
